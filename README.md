# Data City

A 3D data visualization website built for the 3D Websites Hackathon.

## Overview

Data City transforms live data into an interactive 3D cityscape. Each district represents a different data source, with building heights and colors reflecting real values.

## Districts

- Crypto District - Cryptocurrency prices and market caps
- GitHub District - Repository stars and activity  
- Weather District - Global city temperatures
- Stocks District - Major stock prices

## Features

- Interactive 3D environment built with Three.js
- Click buildings for detailed information
- Dynamic animations and lighting effects
- Smooth camera controls

## Technical Stack

- React + Vite
- Three.js + React Three Fiber
- @react-three/drei

## Running Locally

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
```

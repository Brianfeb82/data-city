# DATA CITY 🌃

**Real-time 3D Data Visualization**

A stunning immersive 3D website that transforms live data into a futuristic cityscape. Built for the 3D Websites Hackathon.

## 🎯 Concept

Data City visualizes multiple data sources as a living, breathing 3D metropolis. Each "district" represents a different data type, with buildings whose heights, colors, and animations reflect real-time values.

## 🏙️ Districts

- **Crypto District** - Cryptocurrency prices and market caps
- **GitHub District** - Popular repository stars and activity  
- **Weather District** - Global city temperatures
- **Stocks District** - Major stock prices

## ✨ Features

- **Immersive 3D Environment** - Built with Three.js and React Three Fiber
- **Interactive Buildings** - Click any building to see detailed data
- **Dynamic Animations** - Pulsing lights, rotating rings, floating particles
- **Atmospheric Effects** - Fog, starfield, district halos
- **Smooth Controls** - Intuitive camera rotation and zoom

## 🎨 Design Philosophy

Data City focuses on **aesthetics and wonder** over complexity. The goal is to make people stop and say "Wow" - turning abstract numbers into a beautiful, explorable world.
